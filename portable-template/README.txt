作品集免安装运行包
====================

使用方式
--------
1. 解压整个压缩包，不要只打开压缩包内的文件。
2. 双击 Start-Portfolio.cmd。
3. 稍等片刻，作品集会自动在默认浏览器中打开。
4. 浏览结束后，回到黑色的启动窗口，按 Ctrl+C 停止服务。

运行要求
--------
- 适用于 Windows 10 / Windows 11。
- 不需要安装 Node.js、Vite、npm 或其他前端框架。
- 需要电脑已有现代浏览器（Edge、Chrome、Firefox 等）。
- 运行期间不要移动或删除 site 文件夹。

说明
----
作品集通过电脑本机的 127.0.0.1 地址运行，网页文件不会上传到其他服务器。
如果 5173 端口已被占用，启动脚本会自动选择其他可用端口。
若 Windows 弹出防火墙提示，只需允许本机专用网络访问即可；也可以选择取消，通常仍可在本机浏览。
